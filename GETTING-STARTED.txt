AOPS - Absolute Optical Position Strip Generator
================================================

-----------------------

  run.py                 then starts the GUI. run.py is the cross-platform core.
  README.md              Full documentation: install, architecture, the

QUICK START  (Python 3.12 or later is the only prerequisite)
------------------------------------------------------------
Windows:        double-click  run.bat
Linux / macOS:  ./run.sh

The first run creates .venv, installs dependencies into it, and starts the GUI.
Every run after that starts immediately.

DO NOT run  python src/aops/app.py  directly. The package uses a src layout, so
running a file inside it puts src/aops/ on sys.path instead of src/, and you get

    ModuleNotFoundError: No module named 'aops'

run.py exists to make that mistake impossible - it puts src/ on the path first.
If you already have an environment, plain  python run.py  works too.


RUN
---
    run.bat                          GUI                        (Windows)
    ./run.sh                         GUI                        (Linux/macOS)
    ./run.sh info                    summarise a configuration
    ./run.sh export -o ./out         export PDFs, no GUI needed
    ./run.sh symbol 010500           print one symbol as ASCII

    ./run.sh info -p sample-output/demo-project.aops

The launchers forward every argument through to the CLI, so anything below works
with run.bat / run.sh in front of it.


MANUAL INSTALL  (only if you want to manage the environment yourself)
---------------------------------------------------------------------
Linux / WSL:

    sudo apt-get update
    sudo apt-get install -y libdmtx-dev
    # Only needed for the GUI on a minimal/headless host:
    sudo apt-get install -y libegl1 libxkbcommon-x11-0 libxcb-cursor0 \
        libxcb-icccm4 libxcb-keysyms1 libxcb-shape0 libxcb-render-util0

    python3.12 -m venv .venv
    ./.venv/bin/pip install -r requirements.txt

Windows:
    The pylibdmtx wheel bundles the libdmtx DLL, so there is nothing extra to
    install.

    py -3.12 -m venv .venv
    .venv\Scripts\pip install -r requirements.txt

macOS:
    brew install libdmtx
    python3.12 -m venv .venv
    ./.venv/bin/pip install -r requirements.txt

NOTE: pylibdmtx 0.1.10 cannot import on Python 3.12 unaided - distutils was
removed by PEP 632. AOPS installs a minimal shim before it loads, so no
setuptools dependency and no downgrade is required. See
src/aops/symbols/compat.py.


TEST
----
    QT_QPA_PLATFORM=offscreen ./.venv/bin/python -m pytest
    ./.venv/bin/ruff check src tests

    4260 tests, ~10 seconds.


FIRST THINGS TO CHECK IN THE GUI
--------------------------------
1. Engineering summary tab -> "Required field of view". It is
   N x pitch + symbol, NOT the symbol size. 35 mm at the defaults. A reader
   with a smaller window has blind zones where absolute position is lost.

2. Parameter summary tab -> "Butt-splice error" vs "Datum-aligned error".
   21.1 mm accumulated versus 0.54 mm per tile. This is why every sheet prints
   its own absolute X range and why the guide says to align each tile with a
   steel tape rather than butting them together.

3. Set Media to "Paper" in section 8. It becomes a hard error, quoting the
   predicted humidity drift in millimetres.

4. Set Code type to Code 128. Export is blocked with SYM-001 and the preview
   shows empty outlines - AOPS will not silently substitute a symbology.
